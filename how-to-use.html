How To Use E-Report

Ikuti langkah-langkah berikut untuk membuat, mengirim, dan memantau laporan.

STEP 01

Create Report

Mulai dengan membuka halaman Create Report. Halaman ini digunakan untuk membuat laporan baru.

Isi informasi yang diperlukan seperti judul laporan, kategori, lokasi, deskripsi, dan tingkat prioritas.

Create Report
Create Report Page

Halaman untuk membuat laporan baru.

STEP 02

Fill The Report

Isi semua data laporan dengan jelas agar laporan mudah dipahami.

Jelaskan masalah yang terjadi, lokasi kejadian, dan informasi lain yang diperlukan.

STEP 03

Submit Report

Setelah semua data sudah diisi, periksa kembali laporan sebelum dikirim.

Jika sudah benar, klik tombol Submit Report untuk mengirim laporan.

Submit Your Report

Pastikan data sudah benar sebelum mengirim laporan.

STEP 04

Track Report

Setelah laporan dikirim, kamu dapat memantau perkembangannya melalui halaman Track Report.

Gunakan Report ID untuk mengetahui status laporan.

Track Report
Track Your Report
STEP 05

View History

Gunakan halaman History untuk melihat laporan yang sudah pernah dibuat.

Di halaman ini kamu dapat melihat informasi dan status laporan sebelumnya.

View History
